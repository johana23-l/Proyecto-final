Unidad 1

Arquitectura del Computador y Sistemas

Arquitectura, componentes, sistemas operativos y sistemas de numeración. Un recorrido completo con definiciones, historia, ejemplos prácticos y diagramas modernos.

Arquitectura del Computador

Definición: La arquitectura del computador explica cómo se organiza el hardware y cómo se comunican los componentes para ejecutar instrucciones.

Historia: Surgió con las primeras máquinas de von Neumann y evolucionó hacia sistemas paralelos y arquitecturas multicore.

Importancia: Determina rendimiento, eficiencia y escalabilidad de los sistemas.

Componentes claves

CPU, memoria, almacenamiento, tarjeta gráfica y buses forman el esqueleto de un computador. Cada componente aporta funciones específicas y requiere coordinación precisa.

Función de cada componente

  • CPU: Ejecuta instrucciones y controla operaciones.
  • RAM: Almacena datos temporales y ejecutables.
  • GPU: Procesa gráficos y cálculo paralelo.
  • SSD/HDD: Almacenan datos de forma persistente.

Sistemas Operativos

Definición: Software que gestiona hardware, procesos y permisos. Actúa como intermediario entre aplicaciones y componentes físicos.

Funciones: planificación de CPU, memoria virtual, controladores y seguridad.

Windows

Amplia compatibilidad, entorno gráfico sólido y ecosistema empresarial.

Linux

Flexible, libre y poderoso en servidores y desarrollo. Ideal para administradores y programadores.

macOS

Sistema integrado con Apple, orientado a creatividad, estabilidad y experiencia de usuario.

Sistemas de Numeración

Decimal: Base 10, usado en la vida diaria. Binario: Base 2, base de la computación. Hexadecimal: Base 16, útil para direcciones y colores.

Ejemplo: 173₁₀ = 10101101₂. Convertir usando divisiones sucesivas y lectura de restos.

Unidad 2

Algoritmos, Diagramas de Flujo y Pseudocódigo

Fundamentos de algoritmos, formas de representación visual y el uso de pseudocódigo para planificar soluciones antes de programar.

Definición de algoritmo

Es un conjunto finito de pasos ordenados para resolver un problema. Debe ser claro, determinista y terminar en un número finito de pasos.

Los algoritmos son la base del diseño de software y permiten evaluar eficiencia, complejidad y correctitud.

Diagramas de flujo

Representan visualmente la lógica de un algoritmo usando símbolos estándar. Ayudan a detectar errores y a comunicar procesos complejos.

Símbolos DFD

DFD ayuda a modelar cómo fluyen los datos entre procesos, almacenes y usuarios en un sistema.

Pseudocódigo

Lenguaje informal para describir algoritmos antes de codificarlos. Mantiene la lógica sin detalles de sintaxis específicos.

Leer n
Si n % 2 = 0 Entonces
  Escribir "par"
Sino
  Escribir "impar"
FinSi

Ejemplos prácticos

Promedio: sumar valores y dividir entre la cantidad.

Factorial: multiplicar valores de 1 a n en un ciclo.

Aplicaciones

Los algoritmos se usan en ordenamiento, búsqueda, cálculo numérico, procesamiento de datos y automatización de tareas.

Python, estructuras y Mapas de Karnaugh

Programación en Python con ejemplos prácticos, estructuras lógicas y una introducción visual a la simplificación booleana con Karnaugh.

¿Qué es Python?

Lenguaje interpretado, de tipado dinámico y multiparadigma. Ideal para prototipado rápido, análisis de datos y desarrollo moderno.

Tipos y variables

Python usa tipos como int, float, str, bool, list, tuple y dict. La sintaxis es clara y se basa en indentación.

nombre = 'Johana'
edad = 20
list = [1,2,3]

Control de flujo

Las estructuras if/else y bucles for/while permiten decisiones y repetición. Son esenciales para la lógica de programas.

for i in range(5):
  print(i)
if x > 0:
  print('positivo')

Funciones y estructuras

Encapsula lógica con def y reutiliza código. Listas, tuplas y diccionarios organizan datos en colecciones seguras.

Mapas de Karnaugh

Herramienta para simplificar funciones booleanas. Agrupa unos en un mapa de 2, 3 o 4 variables para obtener expresiones más compactas.

def es_primo(n):
  if n < 2: return False
  i = 2
  while i*i <= n:
    if n % i == 0:
      return False
    i += 1
  return True
