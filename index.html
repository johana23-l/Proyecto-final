Unidad 2 — Algoritmos, Diagramas de Flujo y Pseudocódigo

Esta unidad explora desde los conceptos fundamentales de algoritmo hasta su representación mediante diagramas de flujo y pseudocódigo. Se incluyen ejemplos prácticos, ejercicios resueltos y diagramas ilustrados para consolidar el aprendizaje.

¿Qué es un algoritmo?

Introducción: Un algoritmo es una receta bien definida que transforma entradas en salidas mediante una secuencia finita de pasos. En informática, los algoritmos se implementan como programas y su eficiencia determina la viabilidad de una solución.

Definición: Conjunto finito y ordenado de instrucciones que resuelven una tarea o problema.

Características: Determinismo, finitud, claridad, entrada/salida y efectividad. Un algoritmo debe terminar y producir el resultado esperado en un tiempo razonable.

Importancia: Permiten resolver problemas de manera sistemática, analizar la complejidad temporal/espacial y diseñar soluciones escalables.

Ventajas y aplicaciones

Los algoritmos permiten automatizar tareas, optimizar recursos y formalizar procesos en áreas como búsqueda, ordenación, compresión, encriptación y aprendizaje automático. Son esenciales en diseño de software eficiente y escalable.

Diagramas de Flujo (completo)

Definición: Diagrama gráfico que muestra el flujo de control de un algoritmo usando símbolos estandarizados. Es útil para diseñar, explicar y validar procesos.

Importancia: Facilitan la comunicación entre equipos, ayudan a detectar errores lógicos y sirven como guía para implementar pseudocódigo o código real.

Características: Claridad visual, simbolismo estandarizado, secuencialidad y posibilidad de representar alternativas y ciclos.

Ventajas: Visualización clara, útil para enseñanza y documentación. Desventajas: Pueden volverse complejos en sistemas grandes y requieren mantenimiento.

Pseudocódigo y estructuras

El pseudocódigo es una herramienta intermedia entre el lenguaje natural y un lenguaje de programación. Sirve para planificar algoritmos sin preocuparse por la sintaxis del lenguaje final.

Estructura secuencial

Se ejecutan instrucciones en orden. Ejemplo: calcular área de rectángulo.

				Leer base
				Leer altura
				area = base * altura
				Escribir area

Estructura condicional

Permite decisiones: if / if-else / nested. Ejemplo: determinar positivo/negativo.

				Leer n
				Si n > 0 Entonces
				  Escribir "positivo"
				SinoSi n = 0 Entonces
				  Escribir "cero"
				Sino
				  Escribir "negativo"
				FinSi

Estructura repetitiva

Bucles for y while para repetir acciones. Ejemplo: sumar n primeros enteros.

				Leer n
				sum = 0
				Para i desde 1 hasta n
				  sum = sum + i
				FinPara
				Escribir sum

Enunciado: Dada una lista de calificaciones, calcular el promedio.

Algoritmo: Sumar calificaciones y dividir por cantidad.

Explicación: Multiplicación acumulativa mediante bucle.

Sistemas de Numeración — Teoría y práctica

Los sistemas de numeración permiten representar cantidades mediante símbolos y bases. Son fundamentales en informática para representar datos, direcciones y operaciones lógicas.

Sistema Decimal

Introducción: Es el sistema más utilizado por humanos. Se basa en potencias de diez y es la base natural para conteo.

Definición: Sistema posicional de base 10 que usa dígitos del 0 al 9.

Aplicaciones: Medidas cotidianas, aritmética manual, representaciones en interfaces de usuario.

Sistema Binario

Introducción: Base de la computación digital, usa dos símbolos (0 y 1) y facilita el diseño de circuitos digitales.

Conversiones: 45₁₀ → 101101₂ (divisiones sucesivas). Paso a paso: dividir por 2 y leer restos en orden inverso.

Aplicaciones: Representación interna de datos, lógica booleana y direccionamiento en memoria.

Sistema Octal y Hexadecimal

Octal (base 8) y hexadecimal (base 16) se usan como representaciones compactas para binario: cada dígito octal agrupa 3 bits; hexadecimal agrupa 4 bits (0-F).

Ejemplo: 0x1A = 26₁₀. Las representaciones hex son comunes en direcciones de memoria y colores web.

¿Qué es un algoritmo?

Ventajas: Claridad, replicabilidad, eficiencia.

Diagramas de Flujo

Un diagrama de flujo representa gráficamente la secuencia lógica de un algoritmo utilizando símbolos estandarizados.

Inicio / Fin: Indica el punto de entrada o salida.
Proceso: Operación o acción.
Decisión: Ramifica por condiciones.

Símbolos principales

  • Inicio/Fin
  • Proceso
  • Entrada/Salida
  • Decisión
  • Documento
  • Base de datos
  • Conector

Ejercicio resuelto

Tabla de símbolos (DFD)

Inicio / Fin

Indica el inicio o fin de un proceso.

Proceso

Operación o conjunto de instrucciones que transforman datos.

Entrada / Salida

Representa entrada o salida de datos.

Decisión

Pregunta que determina caminos alternos.

Documento

Salida o registro impreso / archivo.

Base de datos

Conector

Conexión o enlace entre partes del diagrama.

Introducción y historia de Python

Python fue concebido por Guido van Rossum a finales de los años 80 y se lanzó públicamente en 1991. Su diseño busca la legibilidad y la simplicidad, lo que facilita el aprendizaje y la productividad. Python ha evolucionado para ofrecer un amplio ecosistema de bibliotecas en ciencia de datos, web, automatización y más.

Su sintaxis clara y el uso de indentación en lugar de llaves fomentan código legible y mantenible, muy útil en entornos educativos y profesionales.

¿Qué es Python?

Python es un lenguaje interpretado, de tipado dinámico y multiparadigma (soporta programación estructurada, orientada a objetos y funcional). Está orientado a la legibilidad y cuenta con una extensa biblioteca estándar.

Características, ventajas y desventajas

Características: Tipado dinámico, gestión automática de memoria (recolector de basura), gran biblioteca estándar, multiplataforma.

Ventajas: Productividad, comunidad amplia, muchas librerías.

Desventajas: Menor rendimiento en procesos muy intensivos a nivel CPU respecto a lenguajes compilados; algunas incompatibilidades entre versiones mayores (2.x vs 3.x históricamente).

Mapas de Karnaugh — teoría completa

Qué son y para qué sirven

Los Mapas de Karnaugh (K-maps) son una herramienta gráfica para simplificar funciones booleanas. Permiten visualizar agrupamientos de términos (1s) para obtener expresiones minimizadas y así reducir complejidad en circuitos lógicos.

Reglas y procedimiento

  1. Construir la tabla de verdad.
  2. Ubicar los 1s en el mapa de Karnaugh (orden Gray).
  3. Agrupar en potencias de 2 (1,2,4,8...), buscando grupos máximos.
  4. Obtener términos simplificados por grupo.

Ejercicio: Fibonacci iterativo

def fib(n):
    a,b = 0,1
    for _ in range(n):
        a,b = b, a+b
    return a

print([fib(i) for i in range(8)])

Ejercicio: Verificar número primo

def es_primo(n):
    if n < 2: return False
    i = 2
    while i*i <= n:
        if n % i == 0:
            return False
        i += 1
    return True

print(es_primo(17)) # True
